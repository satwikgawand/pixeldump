# pixeldump

browser-based pixel art editor. pick a grid size, build a palette, paint squares, export.

lives at [pixeldump.brnrot.fun](https://pixeldump.brnrot.fun).

## stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Canvas API (no canvas library)

## dev

```bash
npm install
npm run dev
```

## build

```bash
npm run build
```
